GitHub Pages:
1. Crea un repositorio público, por ejemplo: caro
2. Sube index.html y tarjeta-caro.png a la raíz.
3. En el repositorio: Settings > Pages.
4. En Build and deployment, selecciona Deploy from a branch.
5. Branch: main, carpeta /(root), y Save.
6. GitHub mostrará la URL pública.
